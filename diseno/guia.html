Guía · 2 minutos, una sola vez

Conectá TextoVivo a tu IA.

Es un solo conector para toda tu biblioteca. Cuando sumás otro libro, aparece solo.

Todavía no iniciaste sesión. Creá tu cuenta gratis o entrá y tu dirección aparece acá.

Tu dirección de conexiónPrimero obtené tu acceso
  1. 01Abrí Conectores de Claude.
  2. 02Tocá Agregar → Agregar conector personalizado.
  3. 03Nombre: TextoVivo. URL: pegá tu dirección.
  4. 04Tocá Continuar. Si pregunta cómo iniciar sesión, elegí «Sin inicio de sesión».
  5. 05Tocá Agregar.
  6. 06En un chat, abrí + y activá TextoVivo.

El plan gratis de Claude permite un conector personalizado. Por eso TextoVivo es uno solo para todos tus libros.

En planes Team o Enterprise, el conector lo agrega el owner. Después cada persona se conecta con su cuenta.

claude mcp add --transport http textovivo TU_DIRECCION
01Pegá el comando en tu terminal.
02Verificá con claude mcp list que textovivo aparezca conectado.
{ "mcpServers": { "textovivo": { "url": "TU_DIRECCION" } } }
01Pegalo en ~/.cursor/mcp.json.
02Reiniciá Cursor: textovivo aparece en sus herramientas.

¿Algo no funciona?

Claude no me deja agregar otro conector

En el plan gratis de Claude solo entra un conector personalizado. Quitá el que no uses desde Conectores, o pasá a un plan pago de Claude.

La IA dice que mi acceso venció

Renovalo desde Mi biblioteca. No hace falta volver a conectar nada.

La IA no usa TextoVivo

Verificá que el conector esté activado en el menú + del chat, y pedíselo directo: «Usá TextoVivo…».
