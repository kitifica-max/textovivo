Glosario

Siete términos.

  1. 01Terminal · Ventana donde escribes comandos de texto para darle órdenes al ordenador.p. 30
  2. 02Commit · Punto de guardado en git que captura el estado del proyecto con un mensaje.p. 31
  3. 03Branch (rama) · Línea de trabajo paralela en git para cambiar sin tocar la versión principal.p. 31
  4. 04Skill · Conjunto reutilizable de instrucciones y procedimientos que amplían lo que Claude sabe hacer.p. 41
  5. 05Subagentes · Ayudantes especializados que trabajan en paralelo mientras el agente principal coordina.p. 44
  6. 06Plan Mode · Modo en que Claude investiga y propone un plan sin tocar ningún archivo.p. 50
  7. 07Mínimo privilegio · Principio de permisos: confirmar toda acción potencialmente irreversible por defecto.p. 66
